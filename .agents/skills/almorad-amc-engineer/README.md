# ALMORAD AMC AI Engineering Skill

This ready-to-copy skill adapts the uploaded Student Portal coding-agent reference to the ALMORAD AMC website. Main differences: PostgreSQL + Prisma instead of MongoDB/Mongoose; marketing/service SEO and 3D landing instead of academic workflows; receptionist and CEO bookings with staff-reviewed change tickets.

## Installation

Copy the `almorad-amc-engineer/` directory into your repository as `.agents/skills/almorad-amc-full-stack-engineer/` (or the skill directory supported by your AI coding agent). Copy this package's `AGENTS.md` to the repo root, if it doesn't already have one; merge carefully if it does. Copy `references/project-architecture-v4.md` to `docs/architecture.md` and `references/project-design-v3.md` to `docs/design.md` if your repo does not already have newer approved documents. Then prompt the agent to read the skill before implementing a feature.

No code changes, database operations, deployment or third-party integration were performed by creating these instructions.
