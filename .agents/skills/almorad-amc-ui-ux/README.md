# ALMORAD AMC — UI/UX & Motion Design Engineer

Standalone skill for ALMORAD AMC (not Student Portal). Ships complete instructions and references inside this folder. Install/copy this folder to your coding agent's skills directory, then invoke `almorad-amc-ui-ux-designer` or ask for a matching task.

## Included
- `SKILL.md`: complete scope, triggering conditions, inspect/plan/verify workflow
- `AGENTS.md`: independent agent rules
- `agents/openai.yaml`: display metadata
- `references/`: detailed technical and QA guides

## Required project knowledge
The bundled skill summarizes the AMC project. If the real repository is available, read its own `docs/design.md`, `docs/architecture.md`, `AGENTS.md`, lockfiles and code. These live files take precedence on what is implemented. Do not assume any Google account is connected or office address confirmed.

## Database
PostgreSQL + Prisma, no MongoDB/Mongoose.

## Usage example
> Use `almorad-amc-ui-ux-designer` to audit the ALMORAD AMC project for the premium bilingual landing page and provide file-by-file changes, checks and risks.
